Financial Information Agent

A DeepSeek-R1-Distill-Qwen-32B agent combining document RAG, schema-aware SQL, validation, and error-driven retries.

95.7% vs. 78.5% for simple RAG on the same 350-question internal benchmark with predefined reference answers.

Chessformer ↗

Search-free chess with Transformers. Trained on existing ChessBench data and studied attention and positional encoding in JAX.

Advertising in LLMs ↗

An answer-generation and ad-retrieval system using Flask/vLLM, with LoRA + DPO training on 641 human-labeled preferences.

TRUE factual consistency: 0.735 after tuning vs. 0.731 before; no-ad baseline 0.739, across 10 datasets of 1,000 examples each.
